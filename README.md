# Avdragsfrikalkulator

Sammenligner nedbetalingsplanen for et annuitetslån med og uten avdragsfrihet —
terminbeløp, restgjeld og samlet rentekostnad.

**[Åpne kalkulatoren →](https://martin-wahlberg.github.io/avdragsfrikalkulator/)**

Tallene ligger i URL-en, så du kan dele en lenke med dine egne verdier.

> Vibecodet med Claude.

## Kjøre lokalt

```bash
npm install
npm run dev
```
